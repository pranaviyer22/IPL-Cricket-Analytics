# 🏏 IPL Cricket Analytics Dashboard

An end-to-end IPL analytics platform built using Python, Power BI, Streamlit, and Plotly to analyze batting, bowling, venue, and match strategy insights from IPL datasets.

---

# 🚀 Live Project

🔗 Streamlit App:  
https://ipl-cricket-analytics-ueoqvw7szskkdrvzt8xqbm.streamlit.app/

---

# 📌 Project Overview

This project focuses on transforming raw IPL match data into interactive analytical dashboards and visual insights.

The platform includes:
- Batting performance analysis
- Bowling analytics
- Venue intelligence
- Match strategy insights
- Phase-wise scoring analysis
- Interactive filtering and exploration

---

# 🛠️ Tech Stack

- Python
- Pandas
- Power BI
- Streamlit
- Plotly
- Matplotlib
- Seaborn
- Git & GitHub

---

# 📊 Key Features

## 🔹 Batting Analytics
- Top run scorers
- Strike rate analysis
- Batter performance distribution

## 🔹 Bowling Analytics
- Top wicket takers
- Economy rate analysis
- Bowling performance insights

## 🔹 Venue Intelligence
- Highest scoring venues
- Chasing success analysis
- Venue-wise trends

## 🔹 Match Strategy Analysis
- Chasing vs batting first insights
- Powerplay, middle overs, and death overs comparison

## 🔹 Interactive Dashboard
- Team filters
- Venue filters
- Interactive visualizations
- Live Streamlit deployment
